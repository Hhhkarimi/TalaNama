# منابع و روش داده

## منابع داخل ایران

نسخه فعلی طلانما تنها از صفحات عمومی وب‌سایت ایرانی TGJU استفاده می‌کند:

| بازار | نشانی |
|---|---|
| اونس جهانی | https://www.tgju.org/profile/ons |
| طلای ۱۸ عیار | https://www.tgju.org/profile/geram18 |
| دلار آزاد | https://www.tgju.org/profile/price_dollar_rl |

هیچ منبع خارجی در رابط کاربری، کد داده یا مستندات عملیاتی برنامه موردنیاز نیست.

## چرخه به‌روزرسانی

- نقاط تاریخی اصلی در **lib/goldData.js** نگهداری می‌شوند.
- مقادیر روزانه بین نقاط برای نمایش نمودارها به‌صورت قطعی و قابل تکرار بازسازی می‌شوند.
- مسیر **app/api/market/route.js** هر سه صفحه را در سمت سرور می‌خواند.
- پاسخ موفق به مدت ۳۶۰۰ ثانیه در سرور و CDN cache می‌شود.
- رابط در بارگذاری اولیه و سپس هر ۳۶۰۰ ثانیه API داخلی را دوباره درخواست می‌کند.
- قیمت طلای ۱۸ عیار و دلار در منبع ریال است و قبل از نمایش بر ۱۰ تقسیم می‌شود.
- اگر یک منبع موقتاً قطع باشد، وضعیت «بخشی» نمایش داده می‌شود؛ اگر همه منابع قطع باشند، داده پشتیبان جای صفحه خراب را می‌گیرد.
- هیچ درخواست مستقیم مرورگر به دامنه منبع انجام نمی‌شود.
- این داده‌ها فید معاملاتی تضمین‌شده نیستند و نباید برای معامله مستقیم استفاده شوند.

## نکات محیط تولید

برای نسخه تجاری پیشنهاد می‌شود:

1. از API یا فید دارای مجوز یک تأمین‌کننده داخل ایران استفاده شود.
2. کلید API فقط در متغیرهای محیطی Vercel نگهداری شود.
3. قرارداد HTML منبع با آزمون خودکار پایش شود تا تغییر قالب صفحه سریع مشخص شود.
4. در صورت نیاز به تاریخچه واقعی ساعتی، snapshotها در پایگاه داده دارای ماندگاری ثبت شوند.

قبل از scraping یا بازنشر داده، شرایط استفاده و مجوز تأمین‌کننده بررسی شود.
