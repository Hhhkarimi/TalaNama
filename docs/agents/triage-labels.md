# Triage label mapping

These are the proposed default labels from the engineering skills. They are configuration, not currently provisioned repository labels.

| Canonical role | Proposed GitHub label | Meaning |
|---|---|---|
| needs-triage | `needs-triage` | Request has not been classified or verified. |
| needs-info | `needs-info` | A concrete fact required for implementation is missing. |
| ready-for-agent | `ready-for-agent` | Specified, unblocked, and suitable for autonomous implementation. |
| ready-for-human | `ready-for-human` | Requires a durable product, legal, source, or UX decision. |
| wontfix | `wontfix` | Rejected, duplicate, prohibited, or outside approved scope. |

Do not create alternate labels with the same meaning without updating this file.
