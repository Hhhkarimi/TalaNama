# طلانما

داشبورد فارسی و راست‌به‌چپ برای بررسی روند اونس جهانی، طلای ۱۸ عیار، دلار آزاد و عوامل مؤثر بر قیمت طلا در ایران.

این مخزن برای انتشار مستقیم روی **Vercel** آماده است و مسیر ساخت جداگانه‌ای نیز برای **ChatGPT Sites** دارد. نسخه ۱.۱ قیمت جاری را از منابع داخل ایران با چرخه یک‌ساعته دریافت می‌کند.

## قابلیت‌ها

- نمودار ناحیه‌ای، خطی، بازده روزانه و مقایسه‌ای
- بازه‌های یک‌ماهه، سه‌ماهه، شش‌ماهه و یک‌ساله
- میانگین‌های متحرک ۲۰ و ۵۰ روزه و باند بولینگر
- تحلیل تکنیکال، محرک‌های قیمت و ریسک
- سناریوساز تعاملی اونس، دلار و حباب داخلی
- محاسبه‌گر بازده سرمایه
- خروجی CSV
- دریافت ساعتی قیمت جاری از TGJU در Route Handler سمت سرور
- کش یک‌ساعته و نگه‌داشت داده قبلی هنگام قطع موقت منبع
- رابط واکنش‌گرا، فارسی و دارای حالت تاریک

## سیاست منابع داده

تمام لینک‌ها و نقاط مرجع داده در نسخه فعلی فقط از وب‌سایت ایرانی [شبکه اطلاع‌رسانی طلا و ارز](https://www.tgju.org/) استفاده می‌کنند:

- [اونس جهانی](https://www.tgju.org/profile/ons)
- [طلای ۱۸ عیار](https://www.tgju.org/profile/geram18)
- [دلار آزاد](https://www.tgju.org/profile/price_dollar_rl)

مرورگر کاربر هیچ درخواست مستقیمی به TGJU یا سرویس خارجی نمی‌فرستد. Route Handler داخلی برنامه سه صفحه بالا را در سمت سرور می‌خواند، قیمت‌های ریالی را به تومان تبدیل می‌کند و پاسخ را ۳۶۰۰ ثانیه cache می‌کند. داشبورد در شروع و سپس هر ساعت مسیر داخلی `/api/market` را فراخوانی می‌کند. داده‌های روزانه تاریخی بین نقاط مرجع برای نمایش نمودار بازسازی شده‌اند و فید معاملاتی نیستند. جزئیات بیشتر در [مستند منابع داده](docs/DATA_SOURCES.md) آمده است.

## انتشار روی Vercel

### از طریق داشبورد Vercel

1. مخزن را در GitHub ایجاد و کد را push کنید.
2. در Vercel گزینه **Add New → Project** را انتخاب کنید.
3. مخزن GitHub را Import کنید.
4. Vercel به‌صورت خودکار Next.js را تشخیص می‌دهد.
5. بدون تعریف متغیر محیطی، Deploy را اجرا کنید.

تنظیمات آماده در [vercel.json](vercel.json) قرار دارند و Build Command برابر **npm run build** است.

مسیر اصلی برنامه در `app/page.jsx` تعریف شده است؛ در Next.js این فایل معادل صفحه index است و پس از build آدرس `/` را ارائه می‌کند.

### از طریق Vercel CLI

~~~bash
npx vercel
npx vercel --prod
~~~

### نکته مهم درباره آپلود استاتیک

به‌روزرسانی ساعتی به تابع سمت سرور نیاز دارد؛ بنابراین این نسخه را به‌عنوان پروژه **Next.js** از GitHub در Vercel Import کنید یا با Vercel CLI منتشر کنید. بارگذاری یک `index.html` تنها در سرویس استاتیک، API ساعتی را اجرا نمی‌کند.

در پلن Hobby، بازدید اولیه و تایمر یک‌ساعته مرورگر cache را تازه می‌کنند. برای اجرای زمان‌بندی حتی وقتی هیچ بازدیدکننده‌ای آنلاین نیست، پلن Pro می‌تواند Cron زیر را به `vercel.json` اضافه کند:

~~~json
"crons": [{ "path": "/api/market", "schedule": "0 * * * *" }]
~~~

این Cron عمداً در تنظیمات پیش‌فرض قرار نگرفته است، چون طبق [محدودیت رسمی Cron در Vercel](https://vercel.com/docs/cron-jobs/usage-and-pricing)، پلن Hobby اجرای بیش از یک‌بار در روز را نمی‌پذیرد.

## انتشار در GitHub

اگر پوشه هنوز به مخزن GitHub متصل نشده است:

~~~bash
git init
git add .
git commit -m "Initial release"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/talanama-gold-insights.git
git push -u origin main
~~~

پس از push، گردش‌کار CI داخل **.github/workflows/ci.yml** به‌صورت خودکار lint و build را اجرا می‌کند.

## فرمان‌ها

| فرمان | کاربرد |
|---|---|
| npm run dev | توسعه با Next.js |
| npm run build | ساخت استاندارد Vercel |
| npm start | اجرای build تولید |
| npm run lint | بررسی کد |
| npm run test:data-parser | آزمون استخراج قیمت از HTML منبع |
| npm run check | lint و build یکجا |
| npm run dev:sites | توسعه با Vinext |
| npm run build:sites | ساخت مخصوص ChatGPT Sites |

برای ساخت Sites، فایل **.openai/hosting.example.json** را با نام **.openai/hosting.json** کپی و شناسه پروژه خود را جایگزین کنید. این فایل به پروژه خاص متصل است و عمداً از خروجی release عمومی حذف می‌شود.

## ساختار پروژه

~~~text
app/                 رابط اصلی، صفحه index و API ساعتی بازار
components/          نمودارهای بازار و محرک‌ها
lib/goldData.js      داده مرجع و محاسبات تحلیلی
lib/tgju.js          خواندن و اعتبارسنجی قیمت‌های TGJU
docs/                مستندات پروژه
.github/             CI، Dependabot و قالب‌های مشارکت
vercel.json          تنظیمات Vercel
wrangler.jsonc       تنظیمات مسیر Sites/Vinext
~~~
